# Asset Log 사이트 — 설계

## 목적

투자/경제 블로그 "Asset Log"를 위한 개인 사이트. 기존 네이버 블로그를 대체하는 게 아니라, 이 워크스페이스(`my-investor-club-workspace`)의 `blog-write` 스킬로 Claude와 함께 쓴 글이 모이는 곳. 같은 글은 네이버 블로그에도 별도로 발행하는 이중 발행 구조. 대체투자 직무 포트폴리오 성격도 겸함.

## 아키텍처

- **Next.js (App Router)** + 마크다운 콘텐츠 + Tailwind CSS
- 글 하나 = `content/posts/{슬러그}.md` 파일 하나 (frontmatter + 본문)
- 빌드 시점에 마크다운을 읽어 정적 페이지 생성 (gray-matter로 frontmatter 파싱, remark/rehype로 마크다운 → HTML)
- Vercel에 배포, GitHub push 시 자동 재빌드

**비교한 대안**: Astro + Content Collections도 콘텐츠 사이트에 적합하지만, 이후 포트폴리오성 인터랙션을 넣고 싶어질 가능성을 고려해 생태계가 더 넓은 Next.js를 선택.

**범위 밖 (다음 단계로 미룸)**: `blog-write` 스킬이 이 레포의 `content/posts/`에 직접 저장하도록 연결하는 것 — 이번 설계에는 포함하지 않는다. 지금은 사이트 자체만 만든다.

## 콘텐츠 스키마 (frontmatter)

```yaml
---
title: "두나무에 2조가 몰렸다"
date: 2026-07-25
category: RWA   # RWA | STO | 거시 | ...
tags: [RWA, 스테이블코인]
---
```

`title`/`date`/`category`는 필수 — 빠지면 빌드 에러로 표시한다 (조용히 무시하지 않음).

## 페이지 구성

- **홈** (`/`) — 최신 글 목록 (제목 · 날짜 · 카테고리 태그 미리보기)
- **글 상세** (`/posts/{슬러그}`) — 본문 + 상단 카테고리/날짜 + 하단 고정 disclaimer 문구 (기존 style.md 관례 유지: "본 글은 투자 권유가 아닌 개인 학습 목적의 분석입니다...")
- **카테고리 모아보기** (`/categories/{카테고리}`) — 카테고리별 글 목록. 글이 없으면 "아직 없음" 안내
- **소개(About)** (`/about`) — 대체투자 직무 포트폴리오용 자기소개 + 대표 글 링크

내비게이션: 좌측 로고 마크 + "ASSET LOG"(세리프) / 우측 Home · Categories · About.

## 콘텐츠 마이그레이션

- 기존 네이버 블로그(Asset Log) 글은 전량 이전하지 않는다. 대표 글 몇 편만 골라 이 사이트용으로 다시 정리해 옮긴다 (범위는 착수 시 결정).
- 이후 글은 새로 이 사이트 형식으로 작성.

## 에러 처리

- frontmatter 필수 항목 누락 → 빌드 실패로 드러나야 한다 (기본값으로 채워서 통과시키지 않는다).
- 카테고리에 글이 0건이면 빈 화면 대신 "아직 없음" 문구.

## 테스트

- 복잡한 로직이 없는 콘텐츠 사이트이므로: (1) 빌드가 에러 없이 성공하는지, (2) 홈 · 글 상세 · 카테고리 · About을 브라우저로 한 번씩 열어 확인하는 수준으로 충분하다.
